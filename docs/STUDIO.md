# Tessera — studio product brief

## Positioning

International **brain-casual**: Blockudoku loop (place → clear → plan).  
Not art-puzzle (too opaque). Not stack-tap (too shallow).

## Pillars

1. **3-second teach** — coach once, then drag-lift UX  
2. **Think ahead** — weighted shapes, no random soft-lock spam  
3. **Juice** — clear flash, +score float, combo, haptic  
4. **Mobile-first** — 1080×1920, adaptive cell, piece above finger  
5. **Quiet chrome** — score + best; brand on menu only  

## Ship targets

- Android + iOS portrait  
- EN default / VI optional  
- One more try after “No moves”
